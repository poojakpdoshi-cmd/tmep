# MCP client configs

Copy the matching file into your client's config location (see [docs/INTEGRATIONS.md](../../docs/INTEGRATIONS.md)) and replace the paths.

| File | Client | Location |
|---|---|---|
| `claude-code.mcp.json` | Claude Code | `.mcp.json` in your project root |
| `claude_desktop_config.json` | Claude Desktop | `%APPDATA%\Claude\` / `~/Library/Application Support/Claude/` |
| `codex.config.toml` | OpenAI Codex | merge into `~/.codex/config.toml` |
| `cursor.mcp.json` | Cursor | `~/.cursor/mcp.json` or `.cursor/mcp.json` |
| `antigravity.mcp_config.json` | Antigravity | `~/.gemini/config/mcp_config.json` or `.agents/mcp_config.json` |
