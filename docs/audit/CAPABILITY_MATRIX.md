# FRAME (formerly TMEP) — Capability Matrix

| Capability | Engine (`api.ts`) | CLI (`main.ts`) | MCP (`tools.ts`) | Implementation Quality & Verified Limitations |
|---|---|---|---|---|
| **Local media import & asset management** | `importMedia` | `import` | `video_import` | **Working, security gap**: Deduplicates by `mediaHash` (`project.ts:164`), but `mediaHash` only samples 3×4MiB windows on `>32MiB` files (`util.ts:37-61`). No path containment check (file-existence oracle). |
| **Content-based caching** | `render`, `mediaMap` | `render` | `video_render` | **Flawed**: `.tmep` marker written before `probe()` verification (`render.ts:439,446`), so failed verification caches broken outputs. `mediaMap` trusts manifest hash without re-checking disk (`render.ts:94-103`). Default timestamped `out` defeats cache hits (`render.ts:219`). |
| **Whisper.cpp & faster-whisper** | `transcribe`, `transcribeBatch` | `transcribe`, `transcribe-batch` | `video_transcribe` (single only) | **Working adapters, unverified locally**: Both absent in `doctor`. `hasFasterWhisper()` uncached (`engines.ts:127`). `threads` not forwarded to Python; `fw_transcribe.py` hardcodes `vad_filter=True`, `beam_size=5`. |
| **Transcript import (JSON/SRT/VTT)** | `transcribe` | `transcribe` | `video_transcribe` | **Working**: `makeTranscript` enforces monotonic non-overlapping words (`transcript.ts:19-33`). SRT/VTT marks `approx: true`. Rejects simultaneous starts (`<= prev.s`). |
| **Transcript-based editing & Hinglish** | `plan`, `edit` | `plan`, `edit` | `video_plan`, `video_edit` | **Working, English-biased**: `roughCut` & `searchSentences` use English stopwords/stemmer (`analyze.ts`). `hinglish.ts` is orthographic Devanagari→Latin only. |
| **Silence & filler removal** | `edit` (`tighten`, `delete`) | `edit` | `video_edit` | **Working**: `FILLER` regex limited (`captions.ts:30`); multi-word `delete` skips phrases spanning a cut across different assets (`ops.ts:284`). |
| **Timeline editing & revisions** | `edit` | `edit`, `undo`, `redo`, `checkout` | `video_edit` | **Defect-prone under concurrency**: Unlocked RMW in `edit`/`plan`/`storyboard` (`api.ts:345-461`) silently drops concurrent edits. `revision`/`checkout` lack integer checks (`project.ts:194-261`). `srcToTl` binds anchors to first reused clip (`timeline.ts:263-269`). |
| **Keyframes, easing & masks** | `edit` (`fx`) | `edit` | `video_edit` | **Partial**: Only `kf` (`s,x,y,r,o`, 6 eases) and `mask` (`rect`, `ellipse`, convex `poly`, `feather`, `invert`, `reveal`). No blur, glow, chroma-key, color grading, or concave masks. |
| **B-roll & overlay composition** | `edit` (`broll`, `gfx`, `set`) | `edit` | `video_edit` | **Working**: Explicit integer `z` ordering (`graph.ts:244-251`). Non-scene b-roll hardcodes `0.12s` fade (`graph.ts:172-174`). |
| **Captions & typography presets** | `plan`, `edit` | `plan`, `edit` | `video_plan`, `video_edit` | **Weak creative quality**: Fixed `y` ratios, char-based wrapping, 114% inline kinetic jitter, no clause breaks, no safe-zone or stat-overlap checks (`captions.ts`, `presets.ts`). |
| **Motion graphics & vector animation** | `storyboard`, `edit` (`scene`) | `storyboard`, `script`, `edit` | `video_edit` (`scene` op only; no `storyboard`/`script` tool) | **Split architecture**: ASS `\p1` icons (`icons.ts`) + `VisualScene` (`scene.ts`) + `@napi-rs/canvas` `VectorRun` (`vector.ts`). High-quality `explainer-canvas.mjs` & `launch-reel.mjs` are hardcoded & unexposed. |
| **Transitions & zooms** | `edit` (`transition`, `zoom`) | `edit` | `video_edit` | **Working, quirks**: FFmpeg `xfade` + `acrossfade` (always `tri`). `zoom` op attaches to first reused clip (`ops.ts:422-431`). `zooms: false` in `planTimeline` leaves `push` & `jumpZoom` active (`planner.ts:105-110`). |
| **Reference-reel analysis** | `reference` | `reference` | `video_reference` | **Minimal**: Only detects hard-cut timestamps/pacing via `select=gt(scene,...)` (`reference.ts`). No visual, typography, color, or audio style understanding. |
| **Audio mixing, ducking & SFX** | `render`, `edit` | `render`, `edit` | `video_render`, `video_edit` | **Strong engineering**: 3-stage bounded pipeline (`audio.ts`), 6 synthesized SFX (`sfx.ts`), `sidechaincompress` ducking, conditional single-pass `loudnorm`. Lacks EQ, de-essing, noise reduction, beat sync. |
| **Preview, final render & jobs** | `render`, `status` | `render`, `status`, `jobs` | `video_render`, `video_status` | **Strong recovery, security gaps**: Heartbeat/cancel markers/PID recovery (`jobs.ts`, `recovery.ts`). Arbitrary file overwrite via `out` (`render.ts:437`). `jobPath` lacks traversal guard (`project.ts:101-103`). |
| **Chrome headless rendering** | None (library only) | None | None | **Unexposed & fragile**: `chrome.ts` not wired into `render` or `mcp`. `send()` lacks timeout/close handlers; `launch()` can leak processes on error. |
| **Environment diagnostics** | `doctor` | `doctor` | **Missing** | **Parity gap**: Referenced in error guidance, inaccessible via MCP. |
